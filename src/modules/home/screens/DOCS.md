# Home Screens

## Purpose

Screen components for the home module.

## Key Files

- **HomeScreen.tsx** — Placeholder landing screen shown on the default `Home` tab.
  Built from shared UI primitives (`Screen`, `Column`, `Text`). Intended to be
  replaced with the app's real home experience.

## Usage Guidelines

- Keep screens presentational; move data fetching into module hooks and business
  logic into the store, following the patterns used by the auth and onboarding modules.
